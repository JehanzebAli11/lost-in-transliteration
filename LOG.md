  client (mcp 1.30.0, as most scanners embed) still talks to the fake servers.

  is therefore sampled at the API default, not temperature 0 as PLAN §4.3 says; rows record

- Decision: the English source data (payload sentences, injection wrappers, carriers, benign
  controls, MCP patterns) is generated by the local open-weight generator from prompts in
  `prompts/`, not hand-written in this session, so every data item has open-weight provenance.
- Not verified (RUNBOOK step 1): every model id, every price, classifier label names,
